URL บริการตรวจสะกด ?
วิธีติดตั้งและรันบริการตรวจสะกด
1. ติดตั้ง Python 3.9 ขึ้นไป (ดาวน์โหลดจาก python.org)
2. เปิด PowerShell (Windows) หรือ Terminal (Mac) แล้วติดตั้งแพ็กเกจ ครั้งเดียวพอ:
pip install pythainlp pyspellchecker
3. รันบริการ ใส่พาธเต็มของไฟล์ spellcheck_server.py ที่บันทึกไว้ (ลากไฟล์มาวางในหน้าต่างได้):
python "C:\{your save path}\spellcheck_server.py"
4. เห็นข้อความ "spellcheck service on http://127.0.0.1:8765" แสดงว่าพร้อม ต้องเปิดหน้าต่างนั้นค้างไว้ระหว่างใช้งาน
5. กลับมากด "ทดสอบ"
ถ้าเปลี่ยนพอร์ต: python spellcheck_server.py --port 9000 แล้วแก้ URL ให้ตรงกัน รายละเอียดเพิ่มเติมดูใน README.md
