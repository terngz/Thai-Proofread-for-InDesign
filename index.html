How to install and run the spell-check service
1. Install Python 3.9 or later (download from python.org)
2. Open PowerShell (Windows) or Terminal (Mac) and install the packages (one time only):
pip install pythainlp pyspellchecker
3. Run the service using the full path of the saved spellcheck_server.py (you can drag the file into the window):
python "C:\{your save path}\spellcheck_server.py"
4. When you see "spellcheck service on http://127.0.0.1:8765" it is ready. Keep that window open while you work.
5. Come back and press "Test"
To change the port: python spellcheck_server.py --port 9000, then update the URL to match. See README.md for details.
