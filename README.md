# Thai AI Proofreader

ปลั๊กอินพิสูจน์อักษรภาษาไทยและอังกฤษสำหรับ **Adobe InDesign** (UXP) ตรวจคำผิดในเอกสาร แล้วกดไปยังจุดที่ผิดหรือแก้ได้ทันทีจากแผงของปลั๊กอิน

เลือกเครื่องมือตรวจได้ 2 แบบ

| เครื่องมือ | จุดเด่น | สิ่งที่ต้องมี |
|---|---|---|
| **PyThaiNLP** | ออฟไลน์ เร็ว ข้อความไม่ออกจากเครื่อง | รันบริการ `spellcheck_server.py` ด้วย Python |
| **AI Engine** | ตรวจตามบริบทได้แม่นกว่า | Local AI (LM Studio / Ollama) หรือ Cloud API |

> ปลั๊กอินทำหน้าที่ **พิสูจน์อักษรเท่านั้น** ชี้เฉพาะจุดที่สะกดผิดหรือพิมพ์ผิด ไม่ปรับสำนวนและไม่เรียบเรียงใหม่

## ฟีเจอร์

- ตรวจ **ไทย** และ **อังกฤษ** เลือกเปิด/ปิดแต่ละภาษาได้
- เลือกขอบเขตการตรวจ: **ตามที่เลือก** (กรอบ / ข้อความ / ตาราง), **ทั้งหน้าปัจจุบัน** หรือ **ทั้งเอกสาร**
- ผลการตรวจเป็นการ์ด แสดงประเภท, คำผิด → คำที่แนะนำ, เหตุผล และ **เลขหน้า** เรียงตามหน้าในเอกสาร
- **ไปที่จุดนี้**: เลือกคำใน InDesign และเลื่อนไปหน้านั้น (ถ้าคำซ้ำหลายจุด กดซ้ำเพื่อไปจุดถัดไป)
- **แก้เลย / แก้ทั้งหมด**: แก้ข้อความในเอกสารทันที แก้ทั้งหมดรวมเป็น undo ขั้นเดียว (Ctrl/Cmd + Z)
- **แก้แล้ว**: ซ่อนการ์ดนั้น, **ละเว้น**: จดจำคำนั้นไว้ ไม่แจ้งอีก
- **ล้างการตรวจทั้งหมด**: รีเซ็ตผลที่เจอทั้งหมด พร้อมรอตรวจรอบใหม่
- **ล้างรายการคำที่ละเว้น**: เคลียร์คำที่เคยกดละเว้นไว้
- แถบ progress, สถิติ token / ความเร็ว และบันทึกการทำงาน
- ธีมสีตาม InDesign (Dark / Light)

### ประเภทของผลการตรวจ

| ป้าย | ที่มา |
|---|---|
| **กฎ** | กฎอัตโนมัติในปลั๊กอิน (ตรวจได้เร็วและแม่น) |
| **สะกด** | บริการ PyThaiNLP |
| **AI** | โมเดล AI |
| **สงสัย** | คำที่ไม่พบในพจนานุกรมในเครื่อง (อาจเป็นชื่อเฉพาะหรือคำใหม่) |

### กฎอัตโนมัติที่ตรวจ

- สระ / วรรณยุกต์ซ้ำติดกัน, `เ` สองตัว (น่าจะเป็น `แ`)
- สระ / วรรณยุกต์ซ้อนกันผิดตำแหน่ง, สระลอยไม่มีพยัญชนะนำ
- นิคหิต + สระอา (ควรเป็นสระอำ)
- ตัวอักษรอังกฤษแทรกกลางคำไทย
- อักขระแปลกปลอมและอักขระล่องหน (แสดงเป็นรหัส `U+XXXX`)
- พยัญชนะซ้ำเกิน, คำอังกฤษซ้ำติดกัน
- เว้นวรรคไม้ยมก (ๆ) และเว้นวรรคซ้อน (เปิด/ปิดได้ที่ "ตัวเลือกกฎการตรวจ")

### ตรวจจับคำน่าสงสัยด้วยพจนานุกรมในเครื่อง

ใช้ได้ในโหมด PyThaiNLP (ติ๊ก "ตรวจจับคำน่าสงสัยด้วยพจนานุกรมในเครื่อง") ใช้ไฟล์ `words_th.js` / `words_en.js` ร่วมกับตัวตัดคำของระบบ แจ้งเมื่อพบ

- คำที่ไม่มีในพจนานุกรม
- คำซ้ำติดกัน
- ไทยปนอังกฤษในคำเดียว

## การติดตั้ง

1. เปิด **UXP Developer Tool** (ติดตั้งจาก Creative Cloud Desktop)
2. กด **Add Plugin** เลือกไฟล์ `manifest.json` ของโฟลเดอร์ปลั๊กอิน
3. กด **Load** (เปิด InDesign ค้างไว้)
4. เปิดแผง **Thai AI Proofreader** ใน InDesign

### สิทธิ์ใน `manifest.json`

ปลั๊กอินเชื่อมต่อบริการภายนอก (PyThaiNLP, LM Studio, Cloud API) และเปิดลิงก์คู่มือ จึงต้องขอสิทธิ์ดังนี้

```json
"requiredPermissions": {
  "network": { "domains": "all" },
  "launchProcess": { "schemes": ["https"], "extensions": [] }
}
```

### ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| `manifest.json` | ข้อมูลปลั๊กอิน (เวอร์ชันในหน้า "i" อ่านจากไฟล์นี้) |
| `index.html` | หน้าตาแผง |
| `index.js` | ตรรกะหลัก: กฎ, การตัดข้อความเป็นช่วง, ตรวจ, ไปที่จุด / แก้ใน InDesign |
| `providers.js` | ผู้ให้บริการ AI, โปรไฟล์, เก็บ API key, เรียกโมเดล, telemetry, เรียกบริการ PyThaiNLP |
| `settings.js` | หน้าตั้งค่าการเชื่อมต่อ, ทดสอบการเชื่อมต่อ / โมเดล, สลับโหมด |
| `words_th.js`, `words_en.js` | พจนานุกรมสำหรับตรวจคำน่าสงสัย |
| `tools/spellcheck_server.py` | บริการตรวจสะกด PyThaiNLP |

## วิธีใช้

1. เลือก **เครื่องมือตรวจหลัก** (PyThaiNLP หรือ AI Engine) และตั้งค่าตามหัวข้อด้านล่าง
2. เลือก **ตัวเลือกกฎการตรวจ**, **ขอบเขต** และ **ภาษา**
3. กด **ตรวจคำผิด** (กด **หยุด** ได้ระหว่างตรวจ)
4. จัดการแต่ละการ์ด: ไปที่จุดนี้ / แก้เลย / แก้ทั้งหมด / แก้แล้ว / ละเว้น
5. ตรวจรอบใหม่ได้เลย หรือกด **ล้างการตรวจทั้งหมด** เพื่อเคลียร์ผลก่อน

> ถ้าแก้ข้อความในเอกสารเองหลังตรวจ ตำแหน่งในการ์ดอาจไม่ตรง ปลั๊กอินจะแจ้งว่า "ข้อความในเอกสารเปลี่ยนไปแล้ว" ให้กดตรวจใหม่

## โหมด PyThaiNLP

1. ติดตั้ง Python 3.9 ขึ้นไป
2. ติดตั้งแพ็กเกจ (ครั้งเดียว)

   ```bash
   pip install pythainlp pyspellchecker
   ```

3. รันบริการ (เปิดหน้าต่างค้างไว้ระหว่างใช้งาน)

   ```bash
   python "C:\path\to\tools\spellcheck_server.py"
   ```

4. เห็นข้อความ `spellcheck service on http://127.0.0.1:8765` แสดงว่าพร้อม
5. ในแผง กด **ทดสอบ** ข้าง URL บริการ

เปลี่ยนพอร์ตได้ด้วย `--port 9000` แล้วแก้ URL ในแผงให้ตรงกัน

ถ้ากด **ตรวจคำผิด** แล้วยังไม่ได้รันบริการ ปลั๊กอินจะแจ้งว่า "ยังไม่ได้รันบริการ PyThaiNLP" และหยุด โดยไม่ตรวจต่อด้วยกฎหรือพจนานุกรม

### รูปแบบ API ของบริการ

| Endpoint | รายละเอียด |
|---|---|
| `GET /health` | ตรวจว่าบริการพร้อม (อาจส่ง `pythainlp` เป็นเลขเวอร์ชัน) |
| `POST /check` | ส่ง `{ "text": "...", "th": true, "en": true }` รับ `{ "errors": [{ "original", "suggestion", "issue" }] }` |

## โหมด AI Engine

### ผู้ให้บริการที่รองรับ

LM Studio, Ollama (Local) · OpenAI (ChatGPT) · Anthropic (Claude) · Google Gemini · OpenRouter · Groq · Mistral · DeepSeek · xAI (Grok) · Together AI · อื่น ๆ (OpenAI-compatible)

### ตั้งค่าการเชื่อมต่อ

1. เปิดส่วน **โมเดล AI** กด **ตั้งค่า** ข้างช่อง "โปรไฟล์"
2. เลือก **ผู้ให้บริการ** ระบบเติม Base URL และค่าเริ่มต้นให้
3. ใส่ **API key** (เฉพาะ Cloud) และเลือก / พิมพ์ชื่อโมเดล
4. กด **บันทึก**, **ทดสอบการเชื่อมต่อ** และ **ทดสอบโมเดล**
5. สร้างหลายโปรไฟล์ได้ที่ **เพิ่มโปรไฟล์ใหม่** (ลบด้วย **ลบโปรไฟล์** กดยืนยันอีกครั้ง)

LM Studio: โหลดโมเดล (Load) ก่อน แล้วเปิด Local Server

### พารามิเตอร์

| ค่า | ความหมาย |
|---|---|
| MAX TOKENS | จำนวน token ตอบสูงสุดต่อ request |
| TEMP | อุณหภูมิ (งานพิสูจน์อักษรแนะนำค่าต่ำ) |
| THINKING / REASONING | ปิด / ต่ำ / กลาง / สูง / ค่าเริ่มต้นของโมเดล (งานนี้ไม่ต้องคิดลึก ปิดหรือต่ำจะเร็วกว่า) |
| BUDGET | งบ thinking (เฉพาะ Claude) |
| TIMEOUT / RETRY | เวลารอและจำนวนครั้งที่ลองใหม่เมื่อล้มเหลวชั่วคราว |
| พร้อมกัน | จำนวน request ที่ส่งพร้อมกัน |
| CHUNK | จำนวนตัวอักษรต่อ request |
| ใช้ endpoint `/api/v0` | เฉพาะ LM Studio: ดู tok/s จริงและ TTFT |

ถ้าโมเดลไม่รองรับพารามิเตอร์บางตัว ปลั๊กอินจะปรับและลองใหม่ให้อัตโนมัติ

### คำสั่ง AI (System Instruction)

แก้ได้ที่ส่วน **คำสั่ง AI** มี Preset มาตรฐาน และบันทึก Preset ของตัวเองได้ (ลบได้เฉพาะของตัวเอง)

### API key และความเป็นส่วนตัว

- API key เก็บใน secure storage ของ UXP ถ้าใช้ไม่ได้จะเก็บแบบไม่เข้ารหัสในเครื่อง (แผงจะแจ้งว่าเก็บแบบไหน)
- ใช้ **Cloud API** ข้อความในเอกสารจะถูกส่งออกจากเครื่องไปยังผู้ให้บริการนั้น หากเอกสารเป็นความลับ ให้ใช้ PyThaiNLP หรือ Local AI

## ข้อจำกัด

- คำที่ AI / บริการรายงานยาวเกิน 30 ตัวอักษรจะถูกข้าม
- คำเดียวกันแสดงตำแหน่งได้สูงสุด 50 จุดต่อการ์ด
- ข้อความที่ล้นกรอบ (overset) ไปที่จุดไม่ได้ จะแจ้งให้ทราบ
- AI อาจพลาดหรือเสนอคำผิดได้ ควรตรวจทานก่อนกด "แก้ทั้งหมด"

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| "ยังไม่ได้รันบริการ PyThaiNLP" | รัน `spellcheck_server.py` แล้วกด **ทดสอบ** |
| เชื่อมต่อ AI ไม่ได้ | ตรวจ Base URL, เปิด server (LM Studio / Ollama), ตรวจอินเทอร์เน็ต |
| 401 / 403 | API key ไม่ถูกต้อง หมดอายุ หรือไม่มีสิทธิ์ |
| 404 | ตรวจ Base URL และชื่อโมเดล |
| 429 | ถูกจำกัดอัตรา ลดค่า "พร้อมกัน" หรือเพิ่ม RETRY |
| โมเดลตอบไม่เป็น JSON | ลองโมเดลอื่น หรือลด THINKING |
| ลิงก์คู่มือไม่เปิด | เพิ่มสิทธิ์ `launchProcess` ใน `manifest.json` |
