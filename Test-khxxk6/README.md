# AI Proofreader TH/EN (ปลั๊กอิน InDesign)

ปลั๊กอิน InDesign (UXP) สำหรับ **พิสูจน์อักษรภาษาไทยและอังกฤษ** ชี้เฉพาะจุดที่ผิด เช่น สะกดผิด คำเกิน คำซ้ำ อักขระแปลก หรือภาษาอังกฤษที่หลุดเข้ามาผิดที่ โดย **ไม่เกลาหรือเขียนประโยคใหม่** (ทำหน้าที่พิสูจน์อักษร ไม่ใช่บรรณาธิการ)
เจอแล้วกดปุ่มเดียวเพื่อไปที่คำนั้นในเอกสาร (เลือกคำและเด้งไปหน้าที่เจอ) เหมือนฟังก์ชัน Find

## ความสามารถ

- ตรวจ **ไทย / อังกฤษ / ทั้งสองภาษา** (ติ๊กเลือกได้)
- ขอบเขตการตรวจ: **ตามที่เลือก** (กรอบ, ข้อความที่ปาด, ตาราง/แถว/เซลล์) / **ทั้งหน้าปัจจุบัน** / **ทั้งเอกสาร**
- ผลลัพธ์แสดง **เลขหน้า** และเรียงตามลำดับหน้า กด "ไปที่จุดนี้" เพื่อเลือกคำและเด้งไปหน้านั้น (ถ้าอยู่หน้าเดียวกันอยู่แล้วจะไม่เลื่อนหน้า)
- วิธีตรวจหลายแบบ: กฎ, พจนานุกรม, AI, บริการ PyThaiNLP (ดูหัวข้อ [วิธีตรวจ 4 แบบ](#วิธีตรวจ-4-แบบ))
- เชื่อมต่อ AI ได้หลายเจ้า: LM Studio, Ollama, OpenAI (ChatGPT), Anthropic (Claude), Google Gemini, OpenRouter, Groq, Mistral, DeepSeek, xAI และ OpenAI-compatible อื่น ๆ
- แถบความคืบหน้า สถิติ token/ความเร็ว บันทึกการทำงาน และปุ่มทดสอบโมเดล
- ธีมมืด/สว่าง และแถบพับเก็บ (accordion) ให้หน้าต่างไม่สูง

## สิ่งที่ต้องมี

| ส่วน | จำเป็นไหม |
|---|---|
| Adobe InDesign 18.0 ขึ้นไป (มี UXP) | จำเป็น |
| UXP Developer Tool (ติดตั้งจาก Creative Cloud Desktop) | จำเป็นตอนติดตั้งแบบ developer |
| LM Studio / Ollama **หรือ** API key ของผู้ให้บริการ cloud | ต้องมีอย่างใดอย่างหนึ่ง ถ้าอยากใช้ส่วน AI (ตัวเลือก "กฎ + พจนานุกรม" ใช้ได้โดยไม่ต้องมี) |
| Python 3.9 ขึ้นไป + `pythainlp` + `pyspellchecker` | เฉพาะถ้าอยากใช้ตัวเลือก PyThaiNLP |

## ติดตั้งปลั๊กอิน

วางไฟล์เหล่านี้ไว้ในโฟลเดอร์เดียวกัน (ชื่อโฟลเดอร์ตั้งอะไรก็ได้):

```
manifest.json
index.html
index.js
providers.js
settings.js
words_th.js
words_en.js
tools/spellcheck_server.py     (ตัวเลือกเสริม ไม่ต้องอยู่ในโฟลเดอร์ปลั๊กอินก็ได้)
```

ขั้นตอนตามปกติของ UXP Developer Tool:

1. เปิด InDesign ค้างไว้
2. เปิด **UXP Developer Tool** (ต้องเปิดโหมด Developer ตามที่โปรแกรมแจ้งในครั้งแรก)
3. กด **Add Plugin** แล้วเลือกไฟล์ `manifest.json`
4. กด **Load** ที่แถวของปลั๊กอิน
5. ใน InDesign เปิดแพเนลจากเมนู **Plugins > AI Proofreader TH/EN > AI Proofreader Panel**

หมายเหตุ
- ถ้าแก้โค้ดแล้ว ให้กด **Reload** ใน UXP Developer Tool
- ถ้าอยากแจกคนอื่น ใช้ปุ่ม **Package** ใน UXP Developer Tool เพื่อสร้างไฟล์ `.ccx` ให้ติดตั้งผ่าน Creative Cloud (ขั้นตอนนี้ผมยังไม่ได้ทดสอบ)
- ขนาดแพเนลเริ่มต้นตั้งใน `manifest.json` (`preferredDockedSize` / `minimumSize`) มีผลตอนเปิดครั้งแรกหรือหลังรีโหลด

## วิธีใช้งานเร็ว

1. **เลือกสิ่งที่จะตรวจ** ใน InDesign เช่น คลิกในกรอบข้อความ ปาดเลือกข้อความ หรือเลือกกรอบ/ตาราง
2. ในแพเนล แถบ **ขอบเขต และภาษา** เลือกขอบเขตและภาษา
3. กด **ตรวจคำผิด**
4. ดูผลในรายการด้านล่าง กด **ไปที่จุดนี้** เพื่อไปที่คำในเอกสาร
5. ถ้าเป็นชื่อเฉพาะหรือคำที่ถูกอยู่แล้ว กด **ละเว้น** ครั้งต่อไปจะไม่แจ้งอีก (ล้างรายการได้ที่ลิงก์ด้านล่างสุด)

### ป้ายในรายการผลลัพธ์

| ป้าย | ความหมาย |
|---|---|
| **กฎ** | จับได้ด้วยกฎตายตัว เช่น สระซ้อน อักขระแปลก คำอังกฤษซ้ำ (แม่น ไม่เดา) |
| **AI** | โมเดล AI ชี้ว่าผิด และคำนั้นมีอยู่จริงในข้อความต้นฉบับ (ถ้า AI มโนคำที่ไม่มีอยู่จะถูกตัดทิ้ง) |
| **สะกด** | บริการ PyThaiNLP ชี้พร้อมคำแนะนำ |
| **สงสัย** | พจนานุกรมสงสัยแต่ AI ไม่ยืนยันว่าผิด (อาจเป็นชื่อเฉพาะ/คำใหม่) ให้ดูเอง |

### หมายเหตุเรื่องการเลือกขอบเขต

- **คลิกวางเคอร์เซอร์ในข้อความ** หรือเลือก **กรอบ** = ตรวจทั้ง story (รวมกรอบที่ต่อกัน)
- **ปาดเลือกข้อความ** = ตรวจเฉพาะที่ปาด
- เลือก **ตาราง/แถว/คอลัมน์/เซลล์** = ตรวจทีละเซลล์
- **ทั้งหน้าปัจจุบัน** ต้องอยู่ในมุมมอง Layout (ไม่ใช่ Story Editor) และไม่รวมกรอบบน master page

## วิธีตรวจ 4 แบบ

เปิดแถบ **วิธีตรวจ และโหมด AI** เพื่อเลือก (ใช้พร้อมกันได้)

1. **กฎ** (เร็ว ไม่ใช้ AI) จับสระ/วรรณยุกต์ซ้ำหรือซ้อนผิดลำดับ, เ+เ ที่น่าจะเป็น แ, ํา แทน ำ, สระลอย, ตัวอังกฤษ 1 ตัวแทรกกลางคำไทย, อักขระล่องหน/อักขระแปลก/ฟอนต์ไทยเก่า, พยัญชนะซ้ำ 3 ตัวขึ้นไป, คำอังกฤษซ้ำติดกัน (the the)
   - ตัวเลือก "ตรวจเว้นวรรคไม้ยมก (ๆ) และเว้นวรรคซ้อน" ปิดไว้เป็นค่าเริ่มต้น
2. **AI**
   - โหมด **ตรวจทั้งข้อความ**: ละเอียด ช้ากว่า จับคำที่พิมพ์ผิดแล้วบังเอิญเป็นคำจริงได้ดีกว่า
   - โหมด **เฉพาะจุดน่าสงสัย**: ตัดคำด้วย `Intl.Segmenter` แล้วเทียบกับพจนานุกรม (ไทย `words_th.js`, อังกฤษ `words_en.js`) ส่งให้ AI ตัดสินเฉพาะจุดที่สงสัย เร็วกว่า แต่จับไม่ได้ถ้าพิมพ์ผิดแล้วกลายเป็นคำที่มีอยู่จริง และไม่จับภาษาอังกฤษที่ไม่ควรอยู่ในประโยค
   - ถ้าไม่ติ๊ก "ตรวจด้วย AI" ช่องเลือกโหมดจะเป็นสีจางและกดไม่ได้
3. **บริการตรวจสะกด PyThaiNLP** (ตัวเลือกเสริม ต้องรันโปรแกรมแยก ดูหัวข้อถัดไป)
4. ทั้งหมดรวมกันได้ ผลที่ซ้ำตำแหน่งกันจะแสดงครั้งเดียว

## ตั้งค่า AI และผู้ให้บริการ

เปิดแถบ **โมเดล AI** แล้วกดปุ่ม **ตั้งค่า** เพื่อจัดการ "โปรไฟล์การเชื่อมต่อ" (เก็บได้หลายชุด สลับจาก dropdown)

| ผู้ให้บริการ | Base URL เริ่มต้น | ต้องมี API key | ส่งข้อความออกนอกเครื่อง |
|---|---|---|---|
| LM Studio | `http://127.0.0.1:1234/v1` | ไม่ | ไม่ |
| Ollama | `http://127.0.0.1:11434/v1` | ไม่ | ไม่ |
| OpenAI (ChatGPT) | `https://api.openai.com/v1` | ใช่ | ใช่ |
| Anthropic (Claude) | `https://api.anthropic.com/v1` | ใช่ | ใช่ |
| Google Gemini | `https://generativelanguage.googleapis.com/v1beta/openai` | ใช่ | ใช่ |
| OpenRouter / Groq / Mistral / DeepSeek / xAI / Together | ดูในรายการผู้ให้บริการในแอป | ใช่ | ใช่ |
| อื่น ๆ (OpenAI-compatible) | กำหนดเอง | แล้วแต่เจ้า | แล้วแต่เจ้า |

> URL และชื่อโมเดลของแต่ละเจ้าเปลี่ยนได้ตลอดเวลา ถ้าเรียกไม่ได้ให้ตรวจกับเอกสารของผู้ให้บริการอีกครั้ง

### ใช้ LM Studio (เครื่องของคุณ)

1. เปิด LM Studio ดาวน์โหลดและ **Load โมเดล** (แนะนำรุ่น Instruct ขนาด 7B ขึ้นไป โมเดลเล็กกว่านั้นตรวจสะกดไทยได้ไม่ดี)
2. เปิด **Local Server** (พอร์ตเริ่มต้น 1234)
3. ในแพเนล แถบ "โมเดล AI" ควรเห็นจุดสถานะเป็นสีเขียวและมีชื่อโมเดลในรายการ ถ้าไม่เห็นให้กด "รีเฟรช"
4. โมเดลแบบ thinking อาจต้องเพิ่ม **MAX TOKENS** (เช่น 4000–8000) หรือปิด thinking ฝั่ง LM Studio

### ใช้ cloud (ChatGPT / Claude / Gemini / อื่น ๆ)

1. กด **ตั้งค่า** ในแถบโมเดล AI เลือกผู้ให้บริการ
2. วาง **API key** (ปุ่ม "ลบ key" ใช้ลบได้)
3. เลือกหรือพิมพ์ชื่อโมเดล
4. ติ๊ก **รับทราบ** ว่าข้อความจะถูกส่งออกจากเครื่องและอาจมีค่าใช้จ่าย
5. กด **บันทึก** แล้ว **ทดสอบการเชื่อมต่อ** และ **ทดสอบโมเดล**
6. ถ้าตรวจทั้งเอกสารหรือเกิน 15 ช่วง ปลั๊กอินจะแสดงประมาณการจำนวน request/ตัวอักษรก่อน แล้วให้กดปุ่มตรวจซ้ำภายใน 30 วินาทีเพื่อยืนยัน

### ค่าที่ตั้งได้ต่อโปรไฟล์

| ค่า | ความหมาย |
|---|---|
| TEMP | ความสุ่มของคำตอบ (แนะนำ 0 สำหรับงานพิสูจน์อักษร) |
| TIMEOUT | รอได้นานสุดกี่วินาทีต่อ request |
| RETRY | จำนวนครั้งที่ลองใหม่อัตโนมัติเมื่อเจอ 429 / 5xx / หมดเวลา |
| พร้อมกัน | จำนวน request ที่ส่งพร้อมกัน (local ใช้ 1, cloud ใช้ 2–3) |
| CHUNK | จำนวนตัวอักษรต่อ 1 request (local ใช้เล็ก ~800, cloud ใช้ใหญ่ได้ ~2500) |
| วิธีบังคับ JSON | บังคับโครงสร้าง (แนะนำ) / json_object / ไม่บังคับ ปลั๊กอินลดระดับให้เองถ้าโมเดลไม่รองรับ |

### API key เก็บที่ไหน

ปลั๊กอินพยายามใช้ที่เก็บความลับของ UXP (`secureStorage`) ก่อน ถ้าใช้ไม่ได้จะเก็บแบบ **ไม่เข้ารหัส** ในเครื่อง และแสดงข้อความบอกไว้ใต้ช่อง key อย่าใช้ key ที่มีสิทธิ์กว้างหรือไม่มีวงเงินจำกัด

## บริการตรวจสะกด PyThaiNLP (ตัวเลือกเสริม)

เป็นตัวตรวจที่ **ไม่ใช้ LLM** ทำงานบนเครื่องคุณ ใช้ [PyThaiNLP](https://github.com/PyThaiNLP/pythainlp) ตรวจคำไทยที่ไม่อยู่ในพจนานุกรมและเสนอคำแก้ (เช่น ประเทส → ประเทศ, ข้อมุล → ข้อมูล) และ `pyspellchecker` ตรวจภาษาอังกฤษ รายงานเฉพาะจุดที่มีคำแนะนำ

ในแพเนลจะมีปุ่ม **?** ข้างตัวเลือกนี้ (แถบ "วิธีตรวจ และโหมด AI") กดเพื่อดูขั้นตอนโดยย่อ

### ติดตั้ง (ครั้งเดียว)

1. ติดตั้ง [Python](https://www.python.org/downloads/) 3.9 ขึ้นไป (Windows: ติ๊ก "Add python.exe to PATH" ตอนติดตั้ง)
2. เปิด PowerShell (Windows) หรือ Terminal (Mac) แล้วรัน

```
pip install pythainlp pyspellchecker
```

### รันบริการ

ต้องบอก `python` ให้ชี้ไปที่ไฟล์จริง การพิมพ์ `python tools/spellcheck_server.py` เฉย ๆ จะใช้ได้ก็ต่อเมื่ออยู่ในโฟลเดอร์ที่มี `tools` อยู่ข้างใน

**วิธีที่ 1: ใช้พาธเต็ม** (Shift + คลิกขวาที่ไฟล์ > "Copy as path" แล้ววางหลังคำว่า `python `)

```
python "C:\ที่เก็บไฟล์\tools\spellcheck_server.py"
```

**วิธีที่ 2: เข้าไปที่โฟลเดอร์ก่อน**

```
cd "C:\ที่เก็บไฟล์"
python tools/spellcheck_server.py
```

ถ้าสำเร็จจะเห็น

```
spellcheck service on http://127.0.0.1:8765  (English: on)
```

แล้วหน้าต่างจะค้างอยู่ ซึ่งเป็นเรื่องปกติ **ต้องเปิดหน้าต่างนี้ค้างไว้ตลอดตอนใช้งาน** ปิดเมื่อไรบริการหยุดเมื่อนั้น

ตัวเลือกเพิ่มเติม

```
python spellcheck_server.py --port 9000        เปลี่ยนพอร์ต (แล้วแก้ URL ในแพเนลให้ตรงกัน)
python spellcheck_server.py --host 127.0.0.1   ค่าเริ่มต้น รับเฉพาะเครื่องนี้ (แนะนำ)
```

### ทดสอบ

- เปิดเบราว์เซอร์ไปที่ `http://127.0.0.1:8765/health` ควรเห็น `"ok": true`
- ในแพเนล: ติ๊ก **ตรวจด้วยบริการสะกด PyThaiNLP** แล้วกด **ทดสอบบริการ**
  (ถ้าไม่ได้ติ๊ก ช่อง URL และปุ่มทดสอบจะเป็นสีจางและกดไม่ได้)
- ถ้าขึ้นว่า "ไม่มีตัวตรวจอังกฤษ" แปลว่ายังไม่ได้ติดตั้ง `pyspellchecker`

### หลักการทำงาน

ตัดคำด้วย newmm → หาคำที่ไม่อยู่ในพจนานุกรม → ลองรวมกับคำข้างเคียงแล้วถามตัวแนะนำคำสะกด → เลือกคำแก้ที่ต่างจากเดิมน้อยที่สุด (ชอบการแทนที่ตัวอักษรมากกว่าการลบหรือเพิ่ม) ในการทดสอบ จับคำผิดได้ถูกต้องและไม่เตือนในข้อความที่ถูกทั้งหมดที่ทดลอง แต่ไม่ได้การันตีว่าทุกข้อความจะเป็นเช่นนั้น

### ถ้าจะแจกให้คนอื่นใช้

ผู้ใช้ทุกคนต้องติดตั้ง Python และ pip เองเหมือนข้างบน จึงควรถือว่าเป็นส่วนเสริมที่ไม่บังคับ ส่วน "กฎ + พจนานุกรม + AI" ใช้ได้โดยไม่ต้องติดตั้งอะไรเพิ่ม

## ดูว่าโมเดลทำงานอยู่ไหม

- **จุดสถานะ** ที่หัวแถบ "โมเดล AI": เขียว = ใช้ได้, แดง = มีปัญหา (เอาเมาส์ชี้เพื่อดูสาเหตุในบางกรณี), เทา = ยังไม่ทราบ
- **แถบความคืบหน้า** ตอนตรวจ: จำนวนช่วงที่เสร็จ จำนวน request ที่รอ เวลาที่ผ่านไป และเวลาที่เหลือโดยประมาณ
- **บรรทัดสถิติ** ใต้สถานะ: จำนวน request, token เข้า/ออก, tok/s เฉลี่ย, วินาทีต่อ request, จำนวนที่ล้มเหลวหรือตอบผิดรูปแบบ
- **บันทึกการทำงาน** (แถบพับด้านล่าง): รายการ request ล่าสุด และการลองใหม่
- **ทดสอบการเชื่อมต่อ**: ดึงรายชื่อโมเดล วัดความหน่วง
- **ทดสอบโมเดล**: ส่งประโยคตัวอย่างที่ฝังคำผิดไว้ 3 จุด แล้วบอกว่าจับได้กี่จุด ตอบเป็น JSON ถูกรูปแบบหรือไม่ และรายงานเกินกี่จุด ใช้เปรียบเทียบโมเดล

LM Studio จะให้ค่า tok/s และ TTFT จริงผ่าน endpoint `/api/v0` (ปลั๊กอินถอยไปใช้ `/v1` เองถ้าใช้ไม่ได้) ส่วนผู้ให้บริการอื่นปลั๊กอินคำนวณ tok/s จากจำนวน token หารเวลา ซึ่งรวมเวลารอเข้าไปด้วยจึงต่ำกว่าความเร็วจริงเล็กน้อย

## ความเป็นส่วนตัว

| โหมด | ข้อความในเอกสารไปที่ไหน |
|---|---|
| กฎ / พจนานุกรม | ไม่ออกจากปลั๊กอิน |
| LM Studio / Ollama | ส่งไปที่เครื่องเดียวกัน (127.0.0.1) |
| บริการ PyThaiNLP | ส่งไปที่เครื่องเดียวกัน (127.0.0.1) |
| cloud (OpenAI, Claude, Gemini, ...) | **ส่งออกจากเครื่องไปยังผู้ให้บริการ** ต้องติ๊กรับทราบก่อนใช้ ควรอ่านเงื่อนไขการเก็บและใช้ข้อมูลของผู้ให้บริการ โดยเฉพาะกับเอกสารลับของลูกค้า |

`manifest.json` ตั้งสิทธิ์เครือข่ายเป็น `"domains": "all"` เพื่อให้เปลี่ยน URL ได้อิสระ ถ้าต้องการจำกัด ให้แก้เป็นรายการโดเมนที่ใช้จริง

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| จุดสถานะแดง / "เชื่อมต่อไม่ได้" | LM Studio ยังไม่เปิด Local Server หรือพอร์ตไม่ตรง ตรวจ Base URL ใน "ตั้งค่า" แล้วกด "ทดสอบการเชื่อมต่อ" |
| ไม่มีรายชื่อโมเดลใน LM Studio | ยังไม่ได้ Load โมเดล |
| "API key ไม่ถูกต้อง" (401/403) | key ผิดหรือหมดอายุ หรือบัญชียังไม่ได้เปิดบิลลิ่ง |
| "ถูกจำกัดอัตรา" (429) | ลดค่า "พร้อมกัน" ในโปรไฟล์ หรือรอสักครู่ ปลั๊กอินลองใหม่ให้เองตามค่า RETRY |
| "AI ตอบผิดรูปแบบ" | ลองโหมด JSON อื่น เพิ่ม MAX TOKENS (โดยเฉพาะโมเดล thinking) หรือใช้โมเดลที่ใหญ่กว่า |
| เจอ error เกี่ยวกับ CORS กับ Claude | แจ้งปัญหาพร้อมข้อความ error ปลั๊กอินส่ง header ที่จำเป็นไว้แล้วแต่ยังไม่ได้ทดสอบกับ key จริง |
| กด "ไปที่จุดนี้" แล้วขึ้น "ข้อความในเอกสารเปลี่ยนไปแล้ว" | แก้ข้อความหลังตรวจ ตำแหน่งจึงไม่ตรง กดตรวจใหม่ |
| "ข้อความอยู่ในส่วนที่ล้นกรอบ" | ข้อความอยู่ใน overset จึงไม่มีหน้าให้ไป |
| เลือกตารางแล้วไม่พบข้อความ | ข้อความแจ้งจะบอกชนิดที่เลือก (เช่น Cell) ถ้ายังไม่ได้ผล แจ้งชนิดนั้นมา |
| ตัวเลือก "เฉพาะจุดน่าสงสัย" ถูกปิด | ไม่พบ `Intl.Segmenter` หรือไฟล์ `words_th.js` / `words_en.js` ตรวจว่าวางไฟล์ครบ |
| `python: can't open file ...` ใน PowerShell | รันคำสั่งผิดโฟลเดอร์ ใช้พาธเต็มตามหัวข้อ "รันบริการ" |
| "เชื่อมต่อไม่ได้ (รัน spellcheck_server.py หรือยัง?)" | ยังไม่ได้รันบริการ PyThaiNLP, หน้าต่างถูกปิด หรือ URL/พอร์ตไม่ตรง |
| สีตัวอักษรอ่านยาก | กดลิงก์ "ธีม" ด้านล่างสุดเพื่อสลับ อัตโนมัติ / มืด / สว่าง |
| ปุ่มหรือไอคอนเป็นกล่อง ☐ | ฟอนต์ของ UXP ไม่มีสัญลักษณ์/อีโมจิ ปลั๊กอินนี้ใช้ข้อความล้วน ถ้าแก้โค้ดเพิ่มให้เลี่ยงอีโมจิ |

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `manifest.json` | ข้อมูลปลั๊กอิน สิทธิ์ ขนาดแพเนล |
| `index.html` | หน้าตาแพเนลและสไตล์ (ธีมมืด/สว่าง, accordion) |
| `index.js` | ตัวตรวจหลัก: อ่านข้อความจาก InDesign, กฎ, พจนานุกรม, สร้างรายการผลลัพธ์, ไปที่จุดผิด, progress |
| `providers.js` | ผู้ให้บริการ AI, โปรไฟล์, เก็บ API key, retry/timeout, ปรับพารามิเตอร์อัตโนมัติ, สถิติ token |
| `settings.js` | หน้าตั้งค่าการเชื่อมต่อ, ทดสอบ, บันทึกการทำงาน, ตั้งค่าบริการ PyThaiNLP |
| `words_th.js` | รายการคำไทย (จาก PyThaiNLP) |
| `words_en.js` | รายการคำอังกฤษ (จาก dwyl/english-words) |
| `tools/spellcheck_server.py` | บริการตรวจสะกดบนเครื่อง (ตัวเลือกเสริม) |
